## 왜 못 올렸나
클라우드 세션에서 WordPress.com MCP 서버(`wpcom-mcp-*`)가 **세션 시작 시점부터 429로 연결 실패**했다.
약 20분 동안 7회 재시도했으나 계속 같은 상태였다. 게다가 mydooba.com / sunyhill.com 도메인은
컨테이너 egress 프록시에서 차단돼 사이트를 직접 열 수도 없다. 즉 이 세션에서는
`posts.list`(오늘 편수 세기) · `tags.create` · `posts.create`(발행·예약) · `posts.get`(한글 검수)
가 **전부 불가능**했다. 그래서 조사와 원고까지만 끝내 두었다.

**다음 실행이 할 일**: 아래 원고 3편을 그대로 쓰되, ① 오늘 편수부터 `posts.list` 로 세고
② 내부링크 3개를 실제 URL 로 채우고 ③ 썸네일·본문 사진을 붙인 뒤 ④ 발행/예약한다.
원고 안에 `TODO(발행 시)` 주석으로 위치를 표시해 뒀다.
